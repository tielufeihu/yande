# yande

#### 介绍
## 图片管理系统



主要功能实现对图片多tag管理。以及图片的增删改查操作，和图片的增加tag操作。以及tag的增删改查。

实现多tag查询功能，比如我们想找到同时拥有tagA、tagB的图片，就可以用这个功能。

实现token登录和权限功能。例如管理员可以删除图片但是用户不可以，权限功能是动态的，不同角色的权限也是动态可变的。
